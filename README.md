## Featured projects

### [FlowPilot](https://github.com/abhisheksd27/Flowpilot)

A weather and air-quality data platform that transforms Open-Meteo inputs into validated DuckDB tables, anomaly reports, and a public dashboard.

- Preserves raw inputs, validates schema and source consistency, and publishes hourly and daily tables transactionally.
- Uses a LangGraph workflow with bounded repair attempts, incremental collection, backfills, and archived-input replay.
- Runs with a built-in engine without AI credentials; optional model adapters extend the workflow.

**Stack:** Python · SQL · DuckDB · Pandas · Pandera · LangGraph · Streamlit · Docker · GitHub Actions  
**Explore:** [Live dashboard](https://abhisheksd27.github.io/Flowpilot/) · [Source code](https://github.com/abhisheksd27/Flowpilot)

### [ShopLakehouse](https://github.com/abhisheksd27/ShopLakehouse) — In progress

An e-commerce analytics platform with an implemented local pipeline from PostgreSQL, REST APIs, and CSV feeds through Bronze, Silver, and Gold layers to Metabase.

- Immutable Bronze Parquet ingestion, PySpark validation and deduplication, and customer identity protection in Silver.
- dbt facts, dimensions, customer history, and revenue, retention, and marketing analytics.
- Airflow orchestration with quality checks that gate publication and watermark updates.

**Stack:** Python · SQL · PySpark · PostgreSQL · MinIO · dbt · Airflow · Metabase · Docker · Terraform  
**Next:** Deploy and validate the prepared AWS infrastructure; verify cloud integration and recovery.  
**Explore:** [Build progress](https://github.com/abhisheksd27/ShopLakehouse/blob/main/docs/progress.md) · [Source code](https://github.com/abhisheksd27/ShopLakehouse)
